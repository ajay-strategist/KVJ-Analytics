Data Manipulation

Data Manipulation is the process of changing, organizing, or transforming data to make it easier to read or more useful for analysis.

If Raw Data is the unorganized pile of facts, and Data Analysis is the act of finding insights, then Data Manipulation is the "manual labor" of sorting, filtering, and rearranging that pile so the analysis can actually happen.

These data manipulation techniques are crucial for data preparation and analysis in various domains, from business analytics to data science and machine learning. They help ensure data quality, consistency, and usability for decision-making and reporting.

Key Goals of Data Manipulation

  • Consistency: Ensuring all dates, currencies, and names are in the same format (e.g., changing "Jan 1st" and "01/01" all to "2026-01-01").
  • Focus: Removing data that isn't relevant to your current goal so you can work faster.
  • Structure: Rearranging data into rows and columns (or different Python data structures like Dictionaries or Lists).
  • Creation: Generating new data points from existing ones (e.g., taking "Birth Date" and creating an "Age" column).

2.1 Extract Transform and Load (ETL)

Fundamental Understanding of ETL

ETL is a process used in data management to extract data from various sources, transform it into a consistent format, and load it into a destination such as a data warehouse or a database. It involves the following steps:

Extract

Raw data is copied or exported from source locations to a staging area during data extraction.

Transform

In this stage, raw data undergoes data processing. Here data is processed and consolidated for its intended analytical use case.

Load

The converted data is moved from the staging area into the target area warehouse in the final stage.

2.1.1 Extract

The process starts by extracting raw data from relevant data sources, including databases, files, web etc. The extracted data is stored in a landing zone, also called a staging area. A staging area is an intermediate storage where data is only stored temporarily.

2.1.3 Load

In data loading, extract transform, and load (ETL) tools move the transformed data from the staging area into the target data warehouse. For most organizations that use ETL, the process is automated, well defined, continual, and batch driven. Two methods for loading data follow:

Process
⟶
Data Warehouse

Figure: Load Process

Full Load

In full load, the entire data from the source is transformed and moved to the data warehouse. The full load usually takes place the first time you load data from a source system into the data warehouse.

Incremental Load

In incremental load, the ETL tool loads the delta (or difference) between target and source systems at regular intervals. It stores the last extract date so that only records added after this date are loaded.

2.2 Common Data File Format

In data analytics, data is often stored and exchanged in various file formats. Each format has its own strengths and is chosen based on the nature of the data and the intended use.

CSV (Comma Separated Values)

Stands for Comma Separated Values, a plain file that includes data separated by comma(,). It looks similar to an Excel file and is used to import or export huge volumes of data.

Name,Age,City
John,25,New York
Sara,30,London

XML (Extensible Markup Language)

An XML file is a plain text file that uses custom tags to describe the structure of a document. It has the file extension .xml and is highly flexible for representing complex data structures.

<employees>
  <employee>
    <name>John</name>
    <age>25</age>
    <city>New York</city>
  </employee>
</employees>

JSON (JavaScript Object Notation)

A JSON file stores data in a human-readable, text-based format using name-value pairs and arrays. It is commonly used for transferring data between web applications and servers.

{
  "employees": [
    {
      "name": "John",
      "age": 25,
      "city": "New York"
    }
  ]
}

Excel (.xls, .xlsx)

Microsoft Excel files are used for complex data analysis, calculations, and reporting. They support multiple sheets, formulas, and visual elements like charts and pivot tables.

Name Age City
John 25 New York
Sara 30 London

PDF (Portable Document Format)

Portable Document Format files are used to present documents in a fixed layout. They are widely used for distributing read-only reports and summaries that look the same on all devices.

Final Employee Report.pdf

This document contains the summary of employees and their respective locations as of 2024.

2.3 Data Cleaning

Data cleaning, also known as data cleansing or data scrubbing, is the process of identifying and correcting errors and inconsistencies in raw datasets to improve data quality.

Ensuring data is accurate, complete, consistent, and usable is critical for reliable analysis or decision-making. Without cleaning, even the most advanced analysis can lead to "Garbage In, Garbage Out."

Scrubbing Raw Data

2.3.1 Handling Null values

Dealing with Missing or Null values, which may involve imputing missing data or excluding rows with missing values.

Data Imputation is a specific data manipulation technique used to handle missing values in a dataset. In the real world, raw data is rarely perfect. Sensors fail, survey participants skip questions, and systems glitch. If you simply delete every row that has a missing piece of data, you might lose 50% of your information. Imputation allows you to "fill in the blanks" using logical or statistical methods so you can keep the rest of the data for analysis.

Check data Condition

Display a visualization of Age

Because the Age column has a skewness distribution, then we will do imputation of the Age column using median.

Common Imputation Methods

How you choose to fill the gap depends on the type of data:

Method How it Works Best Used For...
Mean Imputation Fill the gap with the average of that column. Quantitative data with no extreme outliers.
Median Imputation Fill the gap with the middle value. Quantitative data where there are "extreme" high or low scores.
Mode Imputation Fill the gap with the most frequent value. Qualitative (Categorical) data, like "City" or "Favorite Color."
Constant Imputation Fill the gap with a specific value like "Unknown" or 0. When the fact that data is missing is important information itself.

2.3.3 Trimming Spaces

Trimming leading and trailing white spaces from text data to ensure consistency across the dataset.

Example:

Suppose you have text " fruits " with extra spaces. By trimming, it becomes "fruits". This ensures that text-based searches and joins work correctly without failing due to hidden spaces.

# Trimming spaces from a single string
data = " Hello, World! "
trimmed_data = data.strip()
trimmed_data
# Trimming spaces for an entire column
df['fruit'] = df['fruit'].str.strip()

2.5 Data Aggregation

Aggregate Functions are mathematical operations performed on a collection of values (a set of data) that return a single, summarizing value.

In the context of our data-to-knowledge journey, aggregate functions are the primary tools used during the Data Manipulation and Analysis stages to turn raw lists into meaningful Information.

2.5.1 Grouping (SUM)

Grouping SUM is an aggregation function that calculates the sum of a specific numerical column within each group. When you group data by one or more columns, you can apply the SUM function to find the total sum of a particular numerical value for each group.

2.6 Summarizing

Summarizing is the process of taking many rows of data and using Aggregate Functions (like SUM, AVG, or COUNT) to turn them into a few key numbers. It collapses the data vertically.

Goal:
To get a "bottom-line" number.
Result:
Lose individual details but gain a clear total.

Practical Example:

Raw Data: 100 rows of individual student test scores.

Summarized Data: One single number—the Average Score (78%).

Python Implementation (Pandas)

# Creating Summary statistics for an overview

2.7 Pivoting

Pivoting is the process of reorganizing or reshaping data to view it from a different perspective, usually to make analysis easier and more meaningful.

Common Uses in Data Analytics:

  • Create structured reports for better insights
