# KVJ Analytics — Website V3 Content Specs (source of truth)

> Finalized page content for the V3 rebuild. Positioning: **premium Analytics / AI / BI /
> Digital-Transformation company** (NOT a training institute). Build each page from this doc.
> All copy is CMS-editable via `/admin/content` (see `CLAUDE.md`). Use exact wording.

## Shared conventions
- **Design:** dark, premium, cinematic, enterprise-SaaS (Apple / Stripe / Linear / Vercel).
  Glassmorphism, cinematic lighting, floating dashboard visuals, micro-interactions, scroll
  storytelling. Build on the existing animation system (no new deps unless approved).
- **Reusable section types** (build once, reuse across pages): Hero (badge · headline ·
  supporting heading · description · primary/secondary CTA · dashboard visual), Card grid,
  Industries row, Numbered Approach/Process timeline, Success Stories (Challenge→Solution→
  Outcome, CMS), FAQ, Final CTA.
- **Never fabricate** numbers, testimonials, clients, awards. Use impact *areas*, not fake stats.
- **CTAs (defaults):** "Schedule a Consultation"/"Contact Us" → `/contact`; "Explore Corporate
  Solutions" → `/corporate`; "Explore Case Studies" → `/impact` (until a `/case-studies` page);
  "Read All Insights" → `/blog`.
